## Compiler lessons
- `x = x <= 9 ? x : 9` gives `cmp ax,9; jle store; mov ax,9` (value already in ax); `x > 9 ? 9 : x` or `x < 9 ? x : 9` do not.
- `f = a || b || c != 2` gives `xor ax,ax; jmp; xor ax,ax; inc ax` (not `cond ? 0 : 1`, which gives mov ax,1).
- `a = b = 0` stores b first; check WRONG TARGETS for the order (D_5B8C = D_5B8E = 0 stores 5B8E first).
- ABS as `((x)<0?-(x):(x))` macro reproduces the double evaluation in F_2665/F_2731.
- `unsigned` switch selector gives `mov si,ax; cmp si,4; jb` before the jump table (F_281F).
