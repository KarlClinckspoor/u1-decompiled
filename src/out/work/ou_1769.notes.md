## Compiler lessons
- `if (!x)` vs `if (x == 0)` changes code: with `moved = 0` before it, `x == 0` made
  `xor ax,ax ... mov [bp+n],ax`, `!x` kept `mov word ptr [bp+n],0` first (F_252C, F_2776).
- 2D extern `struct ent D_31DC[][15]` + `D_ACC6[i] = D_31DC[lvl][i]` gives the inline rep movsw
  copy with `* 0x78` stride; a flat index (lvl*15+i) does not.
- A loop `for(...;c++,i++)` order of the increments follows source order (c++ first in F_1D71).
- `x < 0 ? -x : x` into a local gives the neg/jns pattern (F_286B); ABS macro on an expression
  with a global double-evaluates (F_294E).
- `return;` in the middle of a function gives its own epilogue; the original used if/else with
  the shared epilogue (F_1D71).
- while(--i > 0 && !done) kept i in ax; `i--; } while (i > 0 && !done)` gave dec [mem]/cmp [mem].
