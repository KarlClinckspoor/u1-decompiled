## Compiler lessons
- `a = b = c = d = 0` stores the LEFTMOST variable first (ASM order = source order left to right).
- Several functions have a frame larger than the locals: Lattice reserves temp slots below the
  locals (CSE spills at [bp+0], [bp+4]); nothing to do, it came out right by itself.
- A switch whose lowest case is 0 uses `cmp si,N; jae` (no `jl`); lowest case 1 gives `sub si,1; jl`.
  Case bodies appear in source order (turn commands: 3,4,2,1 in the original).
- `D_0DF8[v][0]` (unsigned char *D_0DF8[]) gives `mov ax,[si+..]; mov si,ax; mov bl,[si]; xor bh,bh`;
  `*D_0DF8[v]` uses DI.
- Comparison results stored in a variable (`f = x == 3;`, `f = x == 2 || x == 1;`) give the
  `xor cx,cx / jmp / xor cx,cx; inc cx` pattern; CSE of `D_AD3E + ex` is automatic.
- `do ... while (!ok && ++cnt <= 500)` and `while (cnt++ < 499)` reproduce the original loops.
