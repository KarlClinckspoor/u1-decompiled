## Compiler lessons
- An early `return;` in a void function compiles to `add sp; pop bp; ret` at that point; the original
  jumped to a shared epilogue, so write nested if/else with no early returns (F_7377, F_794E, F_7B63).
- `if (!x[i])` on a char array gives `cmp byte ptr [bp+si+c],0` (opcode 82h); `x[i] == 0` gives mov al/test al.
- F_7B63 has `sub sp,4` with no locals (compiler's own temp slot), do not add locals.
