## Compiler lessons
- Unused dummy locals DO count: no `sub sp` when a function has no locals and no args, so do not add `int x;`.
- Comparing an unsigned char local with another unsigned char: `lo > c || c > hi` makes a widened-char temp at [bp+0]
  (frame 2 bytes bigger); the same test written `c < lo || c > hi` gives the original code with no temp.
- Lattice compares unsigned char operands (also against an int) unsigned (`jb`/`ja`), not signed.
- Adjacent `x = 0; y = 0;` stores come out in reverse source order, and a leading `xor ax,ax` before other stores
  means the zero stores were written first in the source (`n = 0; y = 0; c = 'b'; i = 1;`).
- `if (!flag && ...)` vs `flag == 0 && ...` changes the code (F_5B8A: store of the call result before/after the compare);
  `if (D_AD46 || r < 38)` + `!flag` form matched.
- Long arithmetic: both `%` and `/` call CXD33; the remainder comes back in CX:DX, the quotient in AX:BX.
  `D_8BA8 % 0x7FFFL / 1500L` reads BX after the second call; `% ... %` reads DX.
- Switch with cases written 39,37,3B: the compares come out in reverse source order (3B,37,39), code blocks in source order.
- `if (D_3AB0 = !D_3AB0)` gives the xor/inc pattern; `return D_AD46 = 1;` gives `mov ax,1; mov [..],ax`.
- `F_40A8(D_0D72[i][0])` (not `*D_0D72[i]`) with `unsigned char *D_0D72[]` for the load through SI.
- A shop-buy loop `do {...; c++; i++;} while (i <= 15 && y < 8)` is a bottom-test loop; a `while (i <= 15)` is top-test with jmp back.
