## Compiler lessons
- A call argument that is a char/array address used with a constant (`F_3E2F(name, D_2058, 820)`) needs `(int)D_2058`
  to reproduce `mov ax,addr; mov bx,820; push bx; push ax` (as in MONDAIN).
- Frame slots at [bp+0..] are compiler temporaries when an argument list contains several calls
  (`F_0953(a, b, c, D_AD3E + r*F_3C8E(), D_AD40 + r*F_3CBB())` spills the call results): do NOT declare dummy locals;
  nested calls in arguments (left to right order) give the temps.
- `dx=0; dy=0;` was emitted with dy stored first by the compiler; the original's order (dx at +4 first) came from
  writing `dy = 0; dx = 0;` (locals declared dx, dy).
- Switch with cases 3,4,2,1 written in that source order: code order follows the source, jump table is by value.
- Partial CSE of a cell address: `a == 0 || a == 7 || a == 6` shares address computation between the first two
  compares only (left-assoc ||). To get a share between the 2nd and 3rd of a longer chain, parenthesise:
  `P || (a == 8 || a == 1 || a == 2) || b != -1`.
- `D_AD56[x][y].a` on a `struct cell [][11]` gives `imul 0x58` for x and `shl cl,3` for y.
- Two stores `D_3B30 = D_3AAC; D_3B32 = D_3AAE;` followed by `F_40FE(D_3AAC, D_3AAE)` only reuse AX/BX (push bx; push ax)
  when D_3B30/D_3B32 are fields of a struct: `D_3B2C[0].x = D_3AAC; D_3B2C[0].y = D_3AAE;`.
- A pair of adjacent 16-bit globals copied together (D_3B24 = D_8BA8, D_3B26 = D_8BAA) is a `long` assignment
  (load high into AX, low into BX, then store).
- Early `return;` gives an inline epilogue each time; the original uses if/else nesting with one shared epilogue
  (F_0CF3, F_118D). Use else-branches when the original jumps to a common end.
- `F_40A8(D_0FD8[106+idx][0])` matched but `F_40A8(*D_0FD8[106+idx])` did not (register choice: BX/CX/SI vs AX/DI).
- A trailing `if (b == -1 || ...) return 0; return i;` in F_0BAA: check which way the original jumps to the epilogue.
