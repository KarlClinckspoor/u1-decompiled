## Compiler lessons
- Every function with calls has a hidden 2-byte slot at [bp+0]; in F_0BE4 a byte compare of an
  array element (`cmp cl,5`) adds one more, so do not declare a temp for it.
- `if (D_0248)` vs `if (D_0248 != 0)` changed the frame (extra `sub sp,2`) in F_1124.
- `a = b = c = 1` stores c first: write the chain right-to-left to get the original store order.
- `t*=3; t/=4;` (two statements) gives the `mov [bp+2],ax` between mul and div.
- `if (a != 3 && ...) {else-part} else call` reproduces "failure code first, `je` to the call".
- Switch of cases 0,7-10 gives a jump table 0..10; table order follows source case order.
